# Vintage radio reference case

This is the original hand-authored procedural radio retained as a compatibility example. Its operational entry is the repository root `index.html`; implementation remains in `src/main.ts` and `src/createObjectModel.ts` so the root example route, capture scripts, and the user's quality-gate artifacts keep working.

It is a reference implementation, not a branch in the scene generator. New generated scenes are driven only by Scene Spec.
